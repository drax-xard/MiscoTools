# Dilstout

**Naughty Tongue** — a portable, offline random name generator that mixes real language
packs to produce person, place, organization, and domain names.

Dilstout is part of [MiscoTools](../README.md). It follows the same house style as the other
tools: no build step, no runtime dependencies, no telemetry, and everything local.

> Status: planning complete. Milestone 1 (scaffold + core engine) not started yet.

## Why

Most name generators either pull from a single shallow word list or produce generic fantasy
syllables. Dilstout instead treats each culture's naming system as a **Language Pack (LAP)**
with explicit phonology, morphology, and naming conventions. Packs can be weighted and mixed,
so a 50/50 Babylonian/Aztec blend is a first-class operation rather than a novelty.

## Features

- **Language Packs (`.lap`)** — phonology, lexicon, name forms, naming conventions, and
  category templates for a language or culture (for example Ancient Babylonian and Aztec).
- **Categories** — person names, location names, organization names (religious, political,
  military, guild), and domain names (nation, kingdom, empire, province, district, town).
- **Pack Mixer** — combine multiple LAPs with independent weights and per-category overrides.
- **Preset Gallery** — save and load mixes as `.lpp` (Language Pack Preset) files.
- **LAP Studio** — schema-driven editor for authoring packs, with a short guide on how to
  research a culture and where to collect the data.
- **Extensible by design** — mixing strategies, renderers, slot resolvers, categories,
  importers, and (later) speakers are registered through a plug-in API.
- **Portable** — static web app, offline-capable PWA, no server required. An optional Tauri
  wrapper is planned for desktop file associations and loading plug-ins from disk.

## Planned layout

```
Dilstout/
  index.html
  manifest.webmanifest
  sw.js
  core/            # RNG, engine, mixing, validation, morphology (UI-agnostic)
  ui/              # mixer, gallery, studio, results
  plugins/         # example plug-ins
  packs/           # bundled .lap files
  presets/         # bundled .lpp files
  schemas/         # JSON Schemas for .lap, .lpp, plug-in manifests
  docs/            # DESIGN.md, ROADMAP.md, authoring and plug-in guides
  tests/           # node --test, no dependencies
```

## Formats

| Extension | Contents |
|---|---|
| `.lap` | Language Pack: UTF-8 JSON, versioned, validated by `schemas/lap.schema.json`. |
| `.lpp` | Language Pack Preset: UTF-8 JSON, list of packs with weights/overrides, seed, strategy, renderer. |

Both formats are plain JSON so they can be inspected, diffed, and generated by scripts.

No dependencies are required. Once M1 lands:

```sh
cd Dilstout
node --test                 # core engine tests
python3 -m http.server 8000 # serve the app during development
```
